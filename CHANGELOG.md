# Changelog

## 0.1.1 — 2026-10-15

Installable as a Claude Code plugin: `claude plugin marketplace add PlatonKuruc/wizalnut-quality-gates`, then `claude plugin install wizalnut-quality-gates@wizalnut`. Adds `.claude-plugin/plugin.json`, `.claude-plugin/marketplace.json` and `hooks/hooks.json`. The gates themselves are unchanged; `install.sh` works as before.
